## Overview & Aesthetics

This dotfiles repository configures a cohesive, distraction-free macOS tiling desktop experience centered around:

- **Tiling Window Management**: Binary space partitioning via `yabai`, animated rounded borders via `jankyborders`, and global modal hotkeys powered by `skhd`.
- **Integrated Notch Status Bar**: A 32pt flush status bar via `sketchybar` matching MacBook notch height, featuring interactive Bento pills for workspace navigation, running apps, system metrics, and Spotify playback.
- **Terminal Efficiency**: High-performance rendering in `Ghostty` (0.6 opacity blur) paired with `tmux` session persistence, popup scratchpads, and rapid project switching.
- **IDE-grade Neovim**: Engineered for modern full-stack engineering (TypeScript, Rust, Python, Java/Spring Boot, SQL, Docker, Lua) using `lazy.nvim`, Mason, Native LSP, Treesitter, and custom Zoro colorscheme.
- **Consistent Palette**: Every CLI tool (`bat`, `btop`, `delta`, `fastfetch`, `fzf`, `ripgrep`, `starship`, `tmux`) shares identical color tokens.

## Installation & Setup

### Automated CLI (`install.sh`)

The repository includes a unified, OS-aware installer script that handles package installation, automated backups, symlinking, theme builds, and diagnostic health checks:

```bash
# 1. Clone dotfiles
git clone https://github.com/<your-username>/dotfiles.git ~/dotfiles
cd ~/dotfiles

# 2. Run the automated installer (installs packages, symlinks, and sets up themes)
./install.sh

# 3. Verify setup health and active services
./install.sh doctor

# To remove dotfiles and restore symlinks at any time:
./install.sh uninstall
```

#### Supported Operating Systems
- **macOS (Darwin)**: Installs Homebrew packages, taps `felixkratz/formulae` (yabai, skhd, sketchybar, borders), casks, fonts, builds the bat cache, and configures TPM.
- **Linux (Debian/Ubuntu, Arch, Fedora)**: Installs cross-platform packages (zsh, tmux, neovim, fzf, starship, zoxide, eza, bat, ripgrep, etc.) and safely skips macOS-exclusive window managers.

### Manual Setup (Reference)

If you prefer to configure components manually:

#### 1. Install Dependencies

Install the core CLI tools, window management packages, and utilities via Homebrew:

```bash
# Taps
brew tap felixkratz/formulae

# Core Window Management & System UI
brew install koekeishiya/formulae/yabai
brew install koekeishiya/formulae/skhd
brew install felixkratz/formulae/sketchybar
brew install felixkratz/formulae/borders

# Terminal, Multiplexer & Shell
brew install ghostty
brew install tmux
brew install starship
brew install zsh-autosuggestions zsh-syntax-highlighting fzf-tab

# Modern CLI Tooling
brew install fzf zoxide eza bat ripgrep fd git-delta lazygit btop fastfetch jq
```

### 3. Symlink Configurations

Configurations are mapped directly to `$HOME` and `$HOME/.config`:

| Tool            | Source in `~/dotfiles`                      | Target Destination                                       |
| :-------------- | :------------------------------------------ | :------------------------------------------------------- |
| **Zsh**         | `zsh/.zshrc`<br>`zsh/.zshenv`               | `~/.zshrc`<br>`~/.zshenv`                                |
| **Neovim**      | `nvim`                                      | `~/.config/nvim`                                         |
| **Ghostty**     | `ghostty/config`<br>`ghostty/themes`        | `~/.config/ghostty/config`<br>`~/.config/ghostty/themes` |
| **Tmux**        | `tmux/.tmux.conf`                           | `~/.tmux.conf`                                           |
| **Starship**    | `starship/starship.toml`                    | `~/.config/starship.toml`                                |
| **Yabai**       | `yabai/yabairc`                             | `~/.config/yabai/yabairc`                                |
| **Skhd**        | `skhd/skhdrc`                               | `~/.config/skhd/skhdrc`                                  |
| **Sketchybar**  | `sketchybar`                                | `~/.config/sketchybar`                                   |
| **Borders**     | `borders/bordersrc`                         | `~/.config/borders/bordersrc`                            |
| **Bat**         | `bat`                                       | `~/.config/bat`                                          |
| **Btop**        | `btop`                                      | `~/.config/btop`                                         |
| **Fastfetch**   | `fastfetch`                                 | `~/.config/fastfetch`                                    |
| **Git & Delta** | `git/.gitconfig`<br>`git/.gitignore_global` | `~/.gitconfig`<br>`~/.gitignore_global`                  |

Run the following commands to create the symlinks:

```bash
mkdir -p ~/.config

# Shell & Environment
ln -sf ~/dotfiles/zsh/.zshrc ~/.zshrc
ln -sf ~/dotfiles/zsh/.zshenv ~/.zshenv

# Terminal & Multiplexer
ln -sfn ~/dotfiles/tmux/.tmux.conf ~/.tmux.conf
mkdir -p ~/.config/ghostty
ln -sf ~/dotfiles/ghostty/config ~/.config/ghostty/config
ln -sfn ~/dotfiles/ghostty/themes ~/.config/ghostty/themes

# Editors & CLI
ln -sfn ~/dotfiles/nvim ~/.config/nvim
ln -sfn ~/dotfiles/bat ~/.config/bat
ln -sfn ~/dotfiles/btop ~/.config/btop
ln -sfn ~/dotfiles/fastfetch ~/.config/fastfetch
ln -sf ~/dotfiles/starship/starship.toml ~/.config/starship.toml
ln -sf ~/dotfiles/git/.gitconfig ~/.gitconfig
ln -sf ~/dotfiles/git/.gitignore_global ~/.gitignore_global

# Window Management & Bar
mkdir -p ~/.config/yabai ~/.config/skhd ~/.config/borders
ln -sf ~/dotfiles/yabai/yabairc ~/.config/yabai/yabairc
ln -sf ~/dotfiles/skhd/skhdrc ~/.config/skhd/skhdrc
ln -sf ~/dotfiles/borders/bordersrc ~/.config/borders/bordersrc
ln -sfn ~/dotfiles/sketchybar ~/.config/sketchybar
```

### 4. Post-Install Setup

1. **Build Bat Theme Cache**:

   ```bash
   bat cache --build
   ```

2. **Install Tmux Plugin Manager (TPM)**:

   ```bash
   git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
   tmux start-server
   tmux new-session -d
   ~/.tmux/plugins/tpm/bin/install_plugins
   tmux kill-server
   ```

3. **macOS Permissions**:
   - Grant **Accessibility** permissions to `yabai`, `skhd`, and your terminal (`Ghostty`) in _System Settings > Privacy & Security > Accessibility_.
   - Start and enable system services:
     ```bash
     brew services start yabai
     brew services start skhd
     brew services start borders
     brew services start sketchybar
     ```

## Component Configurations

### Window Management (yabai & borders)

- **BSP Layout**: Configured with 50/50 split ratios, 10px window gaps, and 12px screen padding.
- **Auto-Balance**: Signals automatically rebalance windows on creation and destruction.
- **Predefined Spaces**: Windows automatically route to designated virtual desktops:
  - **Space 1 (`browsing`)**: Google Chrome, Safari
  - **Space 2 (`ai`)**: Claude, ChatGPT
  - **Space 3 (`coding`)**: Ghostty, WezTerm, VS Code, IntelliJ IDEA, WebStorm
  - **Space 4 (`dev tools`)**: Firefox, Docker Desktop, Insomnia, Postman
  - **Space 5 (`media`)**: Spotify, VLC
- **Floating Rules**: System apps (Finder, Settings, Activity Monitor, 1Password, etc.) automatically float.
- **JankyBorders**: 3.0px rounded active borders glowing in `#4ade80` (emerald) and dimmed to 30% white when inactive.

### Terminal & Multiplexer (Ghostty & tmux)

#### Ghostty

- 0.6 opacity background with 20px Gaussian blur.
- JetBrainsMono Nerd Font (size 12).
- Native macOS Option key as Alt.
- Copy on select enabled with seamless clipboard integration.

#### Tmux

- **Prefix**: `C-s` (rebound from `C-b`).
- **Dev Layout (`prefix + D`)**: Automatically provisions a 3-pane workstation:
  ```
  ┌───────────────────────┬──────────┐
  │                       │  shell   │
  │      Neovim           ├──────────┤
  │                       │  server  │
  └───────────────────────┴──────────┘
  ```
  Automatically detects and queues `just dev`, `pnpm dev`, or `mvn spring-boot:run`.
- **Sessionizer (`prefix + o`)**: Interactive fuzzy-picker (via `zoxide` + `fzf`) to jump directly to any repository in an isolated tmux session.
- **Interactive Command Palette (`prefix + Space`)**: Popup TUI menu for all common tmux commands.
- **Popup TUIs**:
  - `prefix + g`: Floating `lazygit` popup.
  - `prefix + t`: Floating shell scratchpad.
  - `prefix + f`: Interactive `fzf` file navigator.
  - `prefix + b`: Interactive `git branch` switcher.
- **Vim Navigation**: Uninterrupted `C-h / C-j / C-k / C-l` pane navigation across both tmux and Neovim splits.
- **Persistence**: Continuous autosave every 10 minutes via `tmux-resurrect` and `tmux-continuum`.

### Editor (Neovim Zoro Edition)

A high-speed development environment using **Lazy.nvim**:

- **Leader**: `Space`
- **Key Features**:
  - **LSP & Tooling**: Configured with Mason installer for TypeScript/React (`ts_ls`, `tailwindcss`), Python (`pyright`), Rust (`rust_analyzer`), Java (`jdtls`), SQL (`sqlls`), Lua (`lua_ls`), Docker (`dockerls`), and Bash.
  - **Formatting**: `conform.nvim` with format-on-save using `prettierd`, `stylua`, `black`, `isort`, `google-java-format`, and `shfmt`. Manual format via `<leader>mp`.
  - **Completion**: `nvim-cmp` with `luasnip`, `friendly-snippets`, and `lspkind` icons.
  - **Fuzzy Finder**: `telescope.nvim` (`<leader>ff` files, `<leader>fg` live grep, `<leader>fb` buffers, `<leader>fr` recent files).
  - **File Explorer**: `neo-tree.nvim` toggled with `<C-n>`.
  - **Git in Editor**: `gitsigns.nvim` with hunk staging (`<leader>hs`), reset (`<leader>hr`), diff preview (`<leader>hp`), and blame (`<leader>hb`).
  - **Buffer Navigation**: `bufferline.nvim` (cycle buffers with `<Tab>` and `<S-Tab>`, close with `<leader>bd`).
  - **Statusline**: `lualine.nvim` configured with full dynamic Zoro mode colors.
  - **Rich Markdown Mode**: `render-markdown.nvim` automatically renders rich headings, rounded tables, code block cards, bullet points, and checkboxes in Normal mode; seamlessly reverts to raw text in Insert mode for effortless editing (`<leader>mt` to toggle).

### Shell & CLI Tools (zsh, Starship, fzf, git)

#### Custom Zsh Functions

- `mkcd <dir>` / `take <dir>`: Create a directory hierarchy and immediately `cd` into it.
- `fp`: Interactively search `zoxide` recent projects using `fzf` and jump to it.
- `cdf`: Fuzzy find and jump into any directory within `~/Desktop/projects` or `$DOTFILES`.
- `fkill`: Interactively select a running process via `fzf` and terminate it.

#### Aliases

- **Navigation & Listing**:
  - `ls` ➔ `eza --icons=always --color=always --group-directories-first`
  - `ll` ➔ `eza -la --icons=always --git --group-directories-first`
  - `tree` ➔ `eza --tree --icons=always`
- **Modern CLI Replacements**:
  - `cat` ➔ `bat`
  - `grep` ➔ `ripgrep`
  - `find` ➔ `fd`
- **Git Shortcuts**:
  - `g` (git), `gs` / `gst` (status), `ga` / `gaa` (add), `gc` (commit -m), `gp` (push), `gpl` (pull), `gd` (diff), `gco` (checkout), `gb` (branch), `gl` (log graph).
- **Config Quick Edits**:
  - `zshconfig`, `aliasconfig`, `funcsconfig`, `ghosttyconfig`, `starshipconfig`.

## Maintenance & Useful Commands

| **Reload Zsh**               | `source ~/.zshrc` or `sz`                                              |

| **Rebuild Bat Syntax Cache** | `bat cache --build`                                                    |
| **Update Homebrew Packages** | `brew update && brew upgrade`                                          |
