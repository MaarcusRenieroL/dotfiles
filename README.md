## Overview & Aesthetics

This dotfiles repository configures a cohesive, distraction-free macOS tiling desktop experience centered around:

- **Tiling Window Management**: Binary space partitioning via `yabai`, animated rounded borders via `jankyborders`, subtle inactive window dimming, and global modal hotkeys powered by `skhd`.
- **Integrated Notch Status Bar**: A 32pt flush status bar via `sketchybar` matching MacBook notch height, featuring interactive Bento pills for workspace navigation, running apps, system metrics, battery, volume, and clock.
- **Terminal Efficiency**: High-performance GPU rendering in `Ghostty` (0.6 opacity blur, coding ligatures, borderless hidden titlebar) paired with `tmux` session handling, popup scratchpads, and rapid project switching.
- **IDE-grade Neovim**: Engineered for modern full-stack engineering using `lazy.nvim`, Mason, Native LSP, Treesitter, Conform formatting, `flash.nvim` navigation, `nvim-highlight-colors` color previews, and custom Zoro colorscheme.
- **Consistent Palette**: Every CLI tool (`bat`, `btop`, `fastfetch`, `fzf`, `lazygit`, `ripgrep`, `starship`, `tmux`) shares identical color tokens.

## Installation & Setup

### Automated CLI (`install.sh`)

The repository includes a unified, OS-aware installer script that handles package installation, automated backups, symlinking, theme builds, and diagnostic health checks:

```bash
# 1. Clone dotfiles
git clone https://github.com/MaarcusRenieroL/dotfiles.git ~/dotfiles
cd ~/dotfiles

# 2. Run the automated installer (installs Brewfile packages, symlinks, themes)
./install.sh

# 3. Apply optimized macOS system defaults (key repeat, dock speed, finder)
./install.sh macos

# 4. Verify setup health and active services
./install.sh doctor

# To remove dotfiles and restore symlinks at any time:
./install.sh uninstall
```

### Manual Setup (Reference)

```bash
# 1. Install all dependencies via Brewfile
cd ~/dotfiles
brew bundle --file=Brewfile

# 2. Symlink Configurations
mkdir -p ~/.config ~/.config/ghostty ~/.config/lazygit ~/.config/yabai ~/.config/skhd ~/.config/borders

# Shell & Environment
ln -sf ~/dotfiles/zsh/.zshrc ~/.zshrc
ln -sf ~/dotfiles/zsh/.zshenv ~/.zshenv
ln -sf ~/dotfiles/tmux/.tmux.conf ~/.tmux.conf
ln -sf ~/dotfiles/git/.gitconfig ~/.gitconfig
ln -sf ~/dotfiles/git/.gitignore_global ~/.gitignore_global

# Config Directory
ln -sfn ~/dotfiles/nvim ~/.config/nvim
ln -sfn ~/dotfiles/bat ~/.config/bat
ln -sfn ~/dotfiles/btop ~/.config/btop
ln -sfn ~/dotfiles/fastfetch ~/.config/fastfetch
ln -sfn ~/dotfiles/lazygit ~/.config/lazygit
ln -sf ~/dotfiles/starship/starship.toml ~/.config/starship.toml
ln -sf ~/dotfiles/ghostty/config ~/.config/ghostty/config
ln -sfn ~/dotfiles/ghostty/themes ~/.config/ghostty/themes

# Window Management
ln -sf ~/dotfiles/yabai/yabairc ~/.config/yabai/yabairc
ln -sf ~/dotfiles/skhd/skhdrc ~/.config/skhd/skhdrc
ln -sf ~/dotfiles/borders/bordersrc ~/.config/borders/bordersrc
ln -sfn ~/dotfiles/sketchybar ~/.config/sketchybar

# 3. Build Bat Theme Cache
bat cache --build

# 4. Start macOS Services
brew services start yabai
brew services start skhd
brew services start borders
brew services start sketchybar
```

## Component Configurations

### Window Management (yabai & borders)

- **BSP Layout**: Configured with 50/50 split ratios, 10px window gaps, and 12px screen padding.
- **Window Opacity**: Focused active window at `1.0` opacity, inactive background windows dim to `0.92`.
- **Auto-Balance**: Signals automatically rebalance windows on creation and destruction.
- **Predefined Spaces**: Windows automatically route to designated virtual desktops:
  - **Space 1 (`browsing`)**: Google Chrome, Safari
  - **Space 2 (`ai`)**: Claude, ChatGPT
  - **Space 3 (`coding`)**: Ghostty, WezTerm, VS Code, IntelliJ IDEA, WebStorm
  - **Space 4 (`dev tools`)**: Firefox, Docker Desktop, Insomnia, Postman
  - **Space 5 (`media`)**: Spotify, VLC
- **Floating Rules**: System apps (Finder, Settings, Activity Monitor, 1Password, etc.) automatically float.
- **JankyBorders**: 3.0px rounded active borders glowing in `#4ade80` (emerald) and dimmed to 30% white when inactive.

### Hotkeys & Keybindings (skhd)

All window navigation and control is driven through `skhd`.

#### Navigation & Layout

| Keybinding                    | Action                                                  |
| :---------------------------- | :------------------------------------------------------ |
| `alt - h / j / k / l`         | Focus window West / South / North / East                |
| `shift + alt - h / j / k / l` | Warp / swap window position West / South / North / East |
| `ctrl + alt - h / j / k / l`  | Resize window edge by 50px                              |
| `alt - 1 .. 9`                | Focus workspace 1 through 9                             |
| `shift + alt - 1 .. 9`        | Move active window to workspace 1..9 and switch to it   |
| `alt - b`                     | Balance all window splits in the current workspace      |
| `alt - r`                     | Rotate workspace layout 90 degrees                      |
| `alt - x / y`                 | Mirror workspace layout along X or Y axis               |
| `alt - f`                     | Toggle window zoom-fullscreen                           |
| `shift + alt - f`             | Toggle floating state (centered 4x4 grid)               |
| `shift + alt - p`             | Picture-in-picture float preset (bottom-right 5x5 grid) |
| `ctrl + alt - f`              | Toggle native macOS fullscreen                          |
| `ctrl + alt - b / s / 0`      | Set workspace layout: BSP / Stack / Float               |
| `alt - tab`                   | Focus recently accessed window                          |
| `alt - shift - r`             | Restart `yabai` and `skhd` services                     |

#### Scratchpad Dropdown Terminal

| Keybinding                | Action                                                                              |
| :------------------------ | :---------------------------------------------------------------------------------- |
| `alt + \`` (`alt - 0x32`) | Toggle sticky floating drop-down terminal running persistent tmux session `scratch` |

### Terminal & Multiplexer (Ghostty & tmux)

#### Ghostty

- 0.6 opacity background with 20px Gaussian blur.
- JetBrainsMono Nerd Font (size 12) with coding ligatures enabled (`+calt`, `+liga`, `+dlig`).
- Borderless look via `macos-titlebar-style = hidden`.
- Native macOS Option key as Alt.

#### Tmux

- **Prefix**: `C-s` (rebound from `C-b`).
- **Dev Layout (`prefix + D`)**: Automatically provisions a 3-pane workstation (nvim + shell + server).
- **Sessionizer (`prefix + o`)**: Interactive fuzzy-picker (`zoxide` + `fzf`) to jump directly to any repository in an isolated session.
- **Interactive Command Palette (`prefix + Space`)**: Popup TUI menu for all common tmux commands.
- **Popup TUIs**:
  - `prefix + g`: Floating `lazygit` popup.
  - `prefix + t`: Floating shell scratchpad.
  - `prefix + f`: Interactive `fzf` file navigator.
  - `prefix + b`: Interactive `git branch` switcher.
- **Vim Navigation**: Uninterrupted `C-h / C-j / C-k / C-l` pane navigation across both tmux and Neovim splits.

- **Global Config**: Auto-setup remote on push, rebase pulls, auto-stash, rerere enabled, and zdiff3 merge conflicts.

  - `gcb`: `git checkout -b <branch>`
  - `gco`: `git checkout`

### Shell & CLI Tools (zsh, Starship, fzf)

- **Command & Alias Dropdown**: Hitting `<Tab>` on any prefix (e.g. `ga<Tab>`) opens an `fzf-tab` interactive dropdown displaying matching aliases and commands with live definition previews.
- **Prefix History Search**: Type any prefix (e.g. `git `) and use `Up`/`Down` arrows or `Ctrl-P`/`Ctrl-N` to cycle only matching history.
- **Directory Navigation**: `AUTO_CD` (type directory name directly to `cd`) and `AUTO_PUSHD` (`cd -<Tab>` to select recent directories).
- **Custom Functions**:
  - `mkcd <dir>`: Create directory and `cd` into it.
  - `fp`: Interactively search `zoxide` recent projects via `fzf` and jump.
  - `cdf`: Fuzzy find and jump into any directory within projects or dotfiles.
  - `fkill`: Interactively select and terminate a process via `fzf`.
